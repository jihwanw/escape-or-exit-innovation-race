## 1. 구성 요소

- 두 기존기업 L(선두), F(후발)과 잠재 진입자. 기간 t = 1, …, T (주분석 T = 3; 설문의 3년 참조기간에 대응). 할인율 β = 1.
- 기술 사다리 위치 x_i ∈ {0, …, K}. x_i = K에 도달하면 혁신 완료(신상품 출시). 초기 위치 (x_L0, x_F0), x_L0 ≥ x_F0. 격차 d = x_L0 − x_F0, 완료까지 거리 n_i = K − x_i.
- 기간별 행동(활동 중인 기업만): Q(중단, 비가역, 비용 0, 진전 0), C(계속: 비용 c_C, 한 칸 전진 확률 p_C), A(가속: 비용 c_A, 전진 확률 p_A). 볼록성: c_A/c_C > p_A/p_C, p_A > p_C, c_A > c_C. 전진은 한 칸씩.
- 상금(완료 시점에 즉시 수취): 상대보다 먼저 완료하면 V(시장최초), 상대가 이미 완료한 뒤 완료하면 W < V(자사최초), 동시에 완료하면 각 (V+W)/2. T 안에 완료하지 못하면 0. 정규화 V = 1.
- 진입 위협 θ: 매 기간 시작 시(행동 전) 아직 진입이 없었다면 확률 θ로 진입자가 등장한다. 진입자는 프론티어 기술을 가지고 등장하며, **아직 완료하지 못한 기업의 상금을 영구히 λ배로 줄인다**(V→λV, W→λW, 0 ≤ λ < 1). 이미 완료한 기업은 영향을 받지 않는다(진입 탈출). λ = 1이면 진입은 아무 효과가 없다(통제 실험에 사용).
- 경쟁사 행동의 예측 불가능성 σ (주 정의, 설문 문1-2 ⑤ "경쟁사의 행동을 예측하기 어려움"에 대응): 기업이 C 또는 A를 의도하면, 확률 σ로 실제 노력 수준이 {C, A}에서 균등하게 다시 뽑힌다(조직적 실행 마찰). Q는 흔들리지 않는다(중단은 관측 가능한 의도적 결정). 두 기업 모두 흔들리며, 둘 다 이를 안다. 균형은 이 교란이 반영된 기대보수 행렬 위의 내시균형이다.
- σ의 보조 정의(관측 잡음 변형, 강건성): 완전정보 균형 정책을 계산한 뒤, 각 기업이 상대의 위치를 확률 σ_obs로 한 칸 틀리게(위·아래 각 σ_obs/2, [0, K−1]에서 절단) 관측하고 **관측된 상태의 정책**을 쓴다고 보고 결과를 전향 계산한다(제한된 합리성 변형; 베이즈 갱신 없음). 예측 부호가 두 정의에서 모두 성립할 때만 σ 가설을 사전등록 후보로 올린다.

## 2. 기간 내 순서와 상태

상태 = (t, x_L, s_L, x_F, s_F, e). s_i ∈ {0 활동, 1 중단, 2 완료}, e ∈ {0, 1} 진입 여부.
1. 진입 충격: e = 0이면 확률 θ로 e → 1.
2. 활동 중인 기업이 동시에 행동을 선택(의도). 실행 교란(σ) 뒤 실현 행동이 정해진다.
3. 실현 노력에 따라 비용 지불·성공 실현. x_i = K 도달 시 상금 수취(진입 뒤면 λ배), s_i → 2. Q 실현 시 s_i → 1.
4. t → t+1. t = T+1에서 모든 가치 0.

가치함수 U_i(t, 상태) = 그 기간의 진입 충격 전 기대 보수. 단계 게임의 보수 = −비용 + Σ(성공 실현)[상금 + β U_i(t+1, 다음 상태)].

## 3. 균형과 선택 규칙

- 활동 기업이 하나면 단독 최적화(최대값, 동률이면 노력이 낮은 행동).
- 둘이면 3×3 쌍행렬 게임. 순수전략 내시균형을 전부 찾고, 없으면 지지집합 열거로 혼합균형을 찾는다.
- 복수 균형 선택 규칙(주: `welfare`): (1) 두 기업 보수 합이 최대인 균형, (2) 동률이면 기대 가속 횟수가 적은 균형, (3) 그래도 동률이면 거리 n이 큰 기업(같으면 F)이 낮은 노력(Q < C < A)을 취하는 균형. 강건성: `leader`(L 보수 최대), `laggard`(F 보수 최대). 복수 균형이 나온 상태의 비율을 보고한다.
- 중단–지속의 소모전형 복수 균형(한쪽이 중단하는 두 균형)은 이 모형에서 실질적이다. 선택 규칙에 따라 부호가 달라지는 예측은 사전등록에서 제외한다.

## 4. 결과변수(모형 → 설문 대응)

전향 계산(상태 분포를 정확히 전개; 몬테카를로 없음)으로
- P_quit,i = i가 완료 전에 Q를 실현할 확률 → 문11 ③ 중도포기·중단.
- P_accel,i = i가 한 번 이상 A를 **의도**할 확률 → 문2 ⑧ 경쟁사에 앞서 시장 선점(리드타임 전략).
- P_first,i = i가 상대보다 먼저 완료할 확률 + 동시 완료 확률의 절반 → 문6 ① 시장최초 상품혁신.
- P_finish,i, E[비용_i].

**두 버전(2026-11-09 추가, 1차 격자 진단 뒤).** θ는 두 경로로 행동에 들어간다: (i) 진입 **위협**(진입 전 분기의 연속가치에 θ가 들어가 "지금 끝내라/그만두라"는 유인을 만듦), (ii) 진입의 **실현**(e=1 뒤에는 미완료 상금이 이미 λ배라 가속이 무의미해지고 선두도 C로 내려감). 무조건 결과는 (i)와 (ii)의 혼합이며, θ가 클수록 (ii)의 질량이 커서 P_accel,L이 θ에 감소할 수 있다(1차 격자: 82% 위배). 설문 문1-2 ④ "새로운 경쟁사의 진입이 귀사의 시장 지위를 **위협함**"은 진입이 아직 실현되지 않은 기업의 인식이므로, 설문 대응치는 **위협 버전** = 진입이 기간 내에 실현되지 않은 분기에 조건부인 결과(`condition_no_entry=True`; 정규화 상수 (1−θ)^T, 흐름 통계는 잔여 기간 무진입 확률로 가중)다. 무조건 버전은 보조로 보고하고, 두 버전의 부호가 갈리는 예측은 "실현된 진입을 경험한 기업"을 따로 식별할 수 있을 때만(객관 지표: 업종 신생기업률) 검정에 올린다.

## 6. 2기간 해석해 (T = 2, K = 2, x_L0 = 1, x_F0 = 0, σ = 0)

선두는 한 칸, 후발은 두 칸이 남아 있다. s(e) = λ^e. M = (V+W)/2. 단독 기업의 한 칸 가치 g(R) = max{0, −c_C + p_C R, −c_A + p_A R}.

기간 2(진입 충격 뒤 e₂ 확정, s = s(e₂)):
- (2a) 선두 완료·후발 x=1: 후발 단독, 상금 Ws → v_F^{2a}(s) = g(Ws). 선두 0.
- (2b) 선두 완료·후발 x=0: 후발은 완료 불가 → 0.
- (2c) 선두 미완(x=1)·후발 x=1: 마지막 기간 동시 경주. u_i(a_i, a_j) = −c(a_i) + p(a_i)·s·[V − p(a_j)(V − M)]. 상대 노력 p(a_j)가 높을수록 i의 한계 상금 R_j = s[V − p(a_j)(V−M)]이 작아진다. 각 기업의 최적 반응은 R_j의 임계값 함수(A if (p_A−p_C)R_j > c_A−c_C and −c_A+p_A R_j ≥ 0; C if −c_C+p_C R_j ≥ 0 and 가속 조건 불성립; else Q). 내시균형은 고정점이며 복수일 수 있어 §3 선택 규칙을 적용한다.
- (2d) 선두 미완·후발 x=0: 후발 완료 불가 → Q. 선두 단독 v_L^{2d}(s) = g(Vs).
- 선두가 기간 1에 중단한 경우 후발이 x=1이면 단독으로 상금 V: g(Vs).

기간 1(e₁ 확정, s₁ = s(e₁); e₁=0이면 e₂는 확률 θ로 1): E₂[·] = (1−θ)·(e₂=0) + θ·(e₂=1) (e₁=1이면 e₂=1 확정).
- u_L(a_L, a_F) = −c(a_L) + p_L V s₁ + (1−p_L)[p_F E₂u_L^{2c} + (1−p_F) E₂v_L^{2d}]  (a_F = Q면 p_F = 0).
- u_F(a_L, a_F) = −c(a_F) + p_F[p_L E₂v_F^{2a} + (1−p_L) E₂u_F^{2c}]  (a_L ≠ Q);  a_L = Q면 u_F = −c(a_F) + p_F E₂g(Vs₂).
- 기간 1 균형은 이 3×3 게임의 내시균형(§3 선택 규칙).

**명제 1(후발의 퇴장).** 기간 1에서 후발이 C를 택할 때의 기대값은 −c_C + p_C·Φ_F(θ), Φ_F(θ) = p_L E₂v_F^{2a} + (1−p_L)E₂u_F^{2c}. v_F^{2a}, u_F^{2c}는 모두 상금 배율 s에 대해 비감소이고 s(e₂=1) = λ < 1 = s(e₂=0)이므로, **상대의 기간 2 행동이 e₂에 의존하지 않는 한** Φ_F는 θ에 대해 비증가하고, 후발이 C에서 Q로 넘어가는 임계 θ*가 존재한다: θ ≥ θ* ⟺ p_C Φ_F(θ) ≤ c_C. 상대 행동이 진입 여부에 따라 바뀌면(예: 진입 뒤 선두가 가속을 포기) Φ_F의 단조성은 보장되지 않는다 — 이것이 격자 전수 계산을 하는 이유다.

**명제 2(선두의 선점).** 기간 1에서 선두가 C 대신 A를 택할 조건은 (p_A − p_C)[V s₁ − Ψ_L(θ)] > c_A − c_C, Ψ_L(θ) = p_F E₂u_L^{2c} + (1−p_F)E₂v_L^{2d}. 같은 조건에서 Ψ_L은 θ에 대해 비증가이므로 "지금 완료하는 것"과 "미루는 것"의 가치 차 V s₁ − Ψ_L(θ)는 θ에 대해 비감소이고, 가속으로 넘어가는 임계 θ**가 존재한다.

두 명제의 비대칭은 한 가지 사실에서 나온다: 진입은 **아직 완료하지 못한 미래의 상금**만 깎으므로, 완료가 가까운 기업에는 "지금 끝내라"(가속), 멀어서 어차피 진입 뒤에 끝낼 기업에는 "그만두라"(중단)는 유인으로 작용한다. 두 명제의 단조성 조건(상대의 기간 2 행동이 e₂에 둔감)이 깨지는 영역의 크기는 §5의 격자에서 보고한다.

## 7. 통제 실험(보고 전 필수; `results/03_model_controls.json`)

2. **λ = 1 불변성**: 진입이 상금을 깎지 않으면 θ를 바꿔도 모든 결과가 동일해야 한다.
3. **θ = 0 불변성**: 진입이 없으면 λ를 바꿔도 모든 결과가 동일해야 한다.
4. **ε-선점(결정적 극한)**: p_C = p_A = 1, W = 0, x_L0 = K−1, x_F0 = K−2, σ = 0 → 기간 1에 후발 Q, 선두 C(가속은 비용만 더 듦); P_quit,F = 1, P_first,L = 1, P_accel,L = 0.
5. **대칭성**: d = 0인 대칭 상태에서 가치함수가 기업 라벨 교환에 대칭.
6. **확률 보존**: 전향 계산의 상태 분포 합이 매 기간 1.
7. **σ = 0, σ_obs = 0에서 두 σ 정의의 결과 동일**.
