# 외부 객관 지표 (Task 6) — 무엇을 썼고 무엇을 쓰지 않았나

작성 2026-11-10. 수치는 `data/provenance_entry_rates.json`, `results/06_external_merge.json`에서.

## 1. 채택: 업종(중분류)×연도 신생기업률 — 기업생멸행정통계

- 출처: 통계청 기업생멸행정통계, KOSIS OpenAPI 표 `DT_6BD1101` "시도별 산업중분류별 기업 수(활동/신생/소멸)" (KSIC 11차 개정, 2011~; 목록 J2_6_001_004), 전국(objL1=00) 행.
- 항목(API 응답에서 그대로 읽음): T01 활동, T02 신생, T03 소멸, T04 신생률, T05 소멸률. 반환 연도 2016~2025(2011~2015는 이 표에 없음 — "데이터가 존재하지 않습니다"). PRD_DE = 기준연도임을 통계청 2024년 보도자료의 활동기업 7.642백만과 KOSIS 2024행 7,641,751의 일치로 확인. 2025행은 2026-10-21 갱신(LST_CHN_DE).
- 두 경로 확인: 공식 신생률 T04와 100×T02/T01의 최대 차 0.05pp(반올림; 담배 제조업 1건) → 일치.
- 커버리지: KIS 제조 24개 중분류(10~34)와 서비스 33개 중분류 전부 존재. 2024년 결측 2건(08 광업지원, 36 수도업)은 KIS 업종 밖.
- 결합: 파동별 참조기간(2022M 2019~21, 2023S 2020~22, 2024M 2021~23, 2025S 2022~24) 3년 평균 → `entry_rate`(%), 마지막 연도 `entry_rate_last`, 활동기업 수 로그 `log_active_firms`, 파동 내 z점수 `entry_rate_z`. 참조기간 밖 연도 사용 0건(look-ahead 검사). 4파동 16,595개 기업 전부 값 있음.
- **공식 정의(1차 자료, 2026-11-10 확인)**: 국가데이터처 보도자료 *Business Demography Statistics in 2024*(2025-10-23 배포, 영문판 PDF, `docs/sources/`)는 활동기업을 "active enterprises with annual sales or regular workers"(해당 연도 1월 1일~12월 31일), 신생률을 "Enterprise birth rate (B/A*100)"(B 신생기업 수, A 활동기업 수)로 적는다. 같은 자료의 2024년 수치(활동 7,642천·신생 922천·신생률 12.1%)가 KOSIS 2024행과 일치해 PRD_DE가 기준연도임을 확인했다. 제도 사실 카드: `docs/INSTITUTIONAL_FACTS_escape_or_exit.json`(BDS-DEFINITIONS, BDS-SOURCE). 한국어 원문 보도자료는 페이지에 영문 PDF만 있어 받지 못했다.
- **한계(원고에 적을 것)**: 전국 단위 업종 신생률이며, 기업이 실제로 맞닥뜨리는 "지위를 위협하는 진입"과는 거리가 있다(저가 소규모 진입이 다수).

## 2. 보류: 중국 수입 침투율 — 중분류 단위로는 추측 없이 만들 수 없음

계획(Bloom·Draca·Van Reenen식 "업종별 중국 수입/국내 흡수")을 그대로 만들려면 HS 품목 → KSIC 중분류 연계가 필요하다. 조사 결과:

1. **통계청 기업특성별 무역통계(TEC)** `DT_1TEC_P315`(11차)·`DT_1TEC_N315`(10차) "산업별(KSIC) 주요국가별 수출입"에 **중국 수입액이 KSIC 기준으로 있다**(2010~2025). 그러나 (a) 산업 구분이 제조업 **7개 그룹**(음식료·담배 / 섬유·가죽 / 목재·종이·인쇄 / 석탄·석유·화학 / 비금속·금속 / 전기·전자·정밀·기계 / 운송장비·기타)으로 중분류 24개가 아니고, (b) 분류 기준이 **수입 기업의 산업**(통관 기록을 기업등록부에 연계)이라 "제품 시장에 들어오는 중국산"이 아니라 "그 업종 기업이 수입한 금액"이다 — 중간재 수입(공급망)과 경쟁재 수입이 섞인다. 이것은 침투율의 정의와 다른 물건이다.
2. HS6→KSIC 연계표를 스스로 만들어 UN Comtrade로 계산하는 길은 연계표 자체가 검증되지 않은 매핑(규칙 `no_assumptions_in_experiment_code` 위반)이고, 분모(업종별 국내 공급)도 같은 연계가 필요하다.

→ **죽이기 기준 (ii) 적용**: 중분류 수입 침투율은 이번 논문에서 **쓰지 않는다**. 대신 (i) 설문 문항 Q1K2_7 "해외 경쟁사들과의 경쟁이 치열함"을 해외 경쟁의 인식 측정으로 보조 변수에 두고, (ii) TEC 7그룹 중국 수입액(수입 기업 산업 기준)은 "원고에 넣지 않는 민감도"로만 `data/`에 보존할지 사용자가 결정한다(현재 미수집). 원고의 객관 지표는 신생기업률 하나이며, H2·H6의 "실현된 진입"은 이 변수로 검정한다.
